# Granite Reserving Project

This is where the handbook moves into the original Granite Reserving project. The goal is to carry out a year-end reserve review for a fictional Canadian property and casualty insurer, starting with simulated claim records.

The first milestone is to prepare and reconcile the simulated claims and build paid and reported development triangles. Those triangles will support the unpaid claims estimates and the reserve review.

See the [original project scope](https://github.com/cam-leo/Granite-Reserving/blob/main/docs/SCOPE-v2.md) for the simulation and research plan.
