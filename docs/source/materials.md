# Materials

## Python books

1. **Python Crash Course, 3rd edition** by Eric Matthes. First book that we will use to learn variables, loops, functions, and dictionaries in [Python Basics](python-basics.md).
2. **Python for Data Analysis, 3rd edition** by Wes McKinney. Second book that we will use to further learn how to clean, join, and summarize claims data with pandas alongside [Excel to Python](excel-to-python.md).
3. **Python for Excel, 2nd edition** by Felix Zumstein. Third book that we will use to learn how to work with Excel files from Python and automate repeatable reporting tasks.
