# Materials

## Python books

1. **Python Crash Course, 3rd edition** by Eric Matthes. Use it to learn variables, loops, functions, and dictionaries alongside [Python Basics](python-basics.md).
2. **Python for Data Analysis, 3rd edition** by Wes McKinney. Use it to learn how to clean, join, and summarize claims data with pandas alongside [Excel to Python](excel-to-python.md).
3. **Python for Excel, 2nd edition** by Felix Zumstein. Use it to learn how to work with Excel files from Python and automate repeatable reporting tasks.
