# Python Basics

Start with the building blocks of Python, including variables, data types, and basic operations.

## Your first Python script

Save this line in a file called `first.py`. The `print()` function displays the text inside the quotation marks.

```python
print("Hello Actuary!")
```

Open the VS Code terminal in the folder containing `first.py` and run `python first.py`. You should see this output.

```text
Hello Actuary!
```
