# Granite-Reserving
My personal exploratory project in reserving

A full year-end reserve review of a fictional mid-sized Canadian P&C insurer, Granite Lantern Insurance: simulated claim data, triangles, Exam 5 methods, Exam 7 stochastic reserving, reinsurance and IFRS 17. All data is made up.
